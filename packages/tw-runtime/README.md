# @fluxnative/tw-runtime

Runtime Tailwind class resolver for FluxNative UI hosts with no build step (Flux WebView, Snack).

Use it only where there is no build step; Expo apps use Uniwind with the same class contract.

Part of [FluxNative UI](https://github.com/inspireui/fluxnative-ui). Read the [README](https://github.com/inspireui/fluxnative-ui#readme) and [`docs/topics/runtime.md`](https://github.com/inspireui/fluxnative-ui/blob/main/docs/topics/runtime.md) before using it.

The package ships TypeScript source and is v0: pin an exact version.
