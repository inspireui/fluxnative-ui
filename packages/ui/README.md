# @fluxnative/ui

FluxNative UI: React Native components with always-on Liquid Glass navigation chrome, styled with Tailwind v4 classes.

Start with the root README: it covers installing in an Expo app, the Metro config and `global.css`.

Part of [FluxNative UI](https://github.com/inspireui/fluxnative-ui). Read the [README](https://github.com/inspireui/fluxnative-ui#readme) before using it.

The package ships TypeScript source and is v0: pin an exact version.
