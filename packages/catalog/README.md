# @fluxnative/catalog

The template layer of FluxNative UI: dependency-free React Native primitives, a closed tokens file and an icon component, emitted into a Flux template's files/ folder with a drift manifest.

Emit the layer with `npx fluxnative-catalog emit --to <template>/files`, then keep it current with `update`.

Part of [FluxNative UI](https://github.com/inspireui/fluxnative-ui). Read the [README](https://github.com/inspireui/fluxnative-ui#readme) and [`docs/topics/catalog.md`](https://github.com/inspireui/fluxnative-ui/blob/main/docs/topics/catalog.md) before using it.

The package ships TypeScript source and is v0: pin an exact version.
