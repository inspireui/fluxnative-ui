# @fluxnative/icons

FluxNative UI icon table: one closed set of names mapped to SF Symbols, Material Symbols and inline SVG paths, plus an <Icon> that draws the SVG.

Names come from one closed table (`ICON_NAMES`), so an unknown name is a type error.

Part of [FluxNative UI](https://github.com/inspireui/fluxnative-ui). Read the [README](https://github.com/inspireui/fluxnative-ui#readme) before using it.

The package ships TypeScript source and is v0: pin an exact version.
